Noise Battle

A Flutter party game that turns noise-making into a competition, using the microphone to measure and score each player.

  • Flutter
  • Dart
  • Mobile
Live demo ↗ Source code ↗

Noise Battle is a party game for Android built with Flutter. It uses the device microphone to measure the sound each participant makes (clapping, cheering, shouting) and crowns whoever is loudest.

Features

  • Sound level measurement for each participant, using Flutter audio plugins.
  • Real-time scoring based on intensity and duration.
  • Multiple players taking turns on a single device.
  • Animated feedback so the game feels alive while you play.

How it works

  1. Players gather around the phone.
  2. Each player takes a turn making as much noise as they can.
  3. The app measures the level and duration and shows the score live.
  4. When every turn is done, the loudest player wins.
